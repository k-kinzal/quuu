# AGENTS

## Overview

Quuu is a **macOS app that manages AI agent runs**. An agent working in this
repository (Claude Code / Codex / …) has, more often than not, been **launched by
Quuu itself**. Read everything here with that premise: you are rebuilding the
thing that is running you.

Start with [README.md](README.md) for what the product does. Follow the documents
below before editing.

## Vision

Quuu aims for kinzal to live a more human life.

He keeps a dozen-odd projects. His days went to handing what he had written in
a notepad to whichever AI was free. No rest — all of it so the AIs would keep
running at peak efficiency.

What he builds carries his taste so strongly that making everything simple is
hard. This project's purpose is still to let him live a little more like a
human.
